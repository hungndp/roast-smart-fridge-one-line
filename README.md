One line, 105 characters, roasting the smart fridge — built for make.fun's "Roast the Smart Fridge: One Line, Best Laugh Wins" bounty. The entry is the line itself: `main.py` writes it to `/output/entry.txt`, byte-identical on every run.

> My smart fridge logged 11 openings tonight, zero snacks taken, and still lights up hoping I love it back.

The roast keeps a proven fridge setup — the human opening the door again and again and taking nothing — and lands an emotional reversal instead of wordplay: the fridge is not a cold appliance keeping score, it is a jilted lover still lighting up hoping to be loved back. One mechanism, one incident, twist word last.

## Run it

```sh
python3 main.py
```
